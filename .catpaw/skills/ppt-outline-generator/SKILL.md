# PPT Outline Generator

Use this skill during outline generation. Read `source_summary.json`, preserve only source-backed claims, and produce `outline.json` matching `outline.schema.json`.

Rules:

- Create a coherent 8-20 slide business/project-report storyline.
- Include cover, background/problem, solution/product, evidence/value, roadmap or closing sections.
- Keep slide titles concise and user-reviewable.
- Put uncertain claims in assumptions or review notes instead of presenting them as facts.
- Every source-backed bullet should carry available `source_refs`.
